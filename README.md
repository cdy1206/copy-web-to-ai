# Copy Web to AI

把网页、AI 对话和公式，一键复制成 AI 能读懂的 Markdown/LaTeX。

Copy Web to AI 是一个 Chrome/Edge 浏览器插件。它把 ChatGPT、Gemini、Claude、DeepSeek 和普通网页里的内容复制成更适合投喂 AI 的 Markdown/LaTeX。能直接从网页读取的内容，就在本地完成；遇到图片、canvas、扫描件或真的复制不了的区域，再由你手动框选后交给 MinerU OCR。

一句话：你看到的网页内容，尽量变成 AI 能继续理解和处理的干净文本。

## 你可以用它做什么

想把 ChatGPT 的回答发给另一个 AI？点 `复制当前回答`。

想整理一整段 AI 对话？点 `复制可见会话`。

想把网页正文、公式、代码、表格一起喂给 AI？点 `复制整页`。

想只拿一小段内容？选中文本后点 `复制选区`。

想复制页面上不能选中的内容？先试 `解锁复制`。

如果那块内容本来就是图片或 canvas？用 `框选 OCR`。

## 快速开始

### 1. 下载插件包

如果你只是想安装使用，不要下载 GitHub 的源码 ZIP。源码 ZIP 里面没有构建后的 `dist`，浏览器不能直接当插件加载。

请下载已经打包好的插件包：

- [copy-web-to-ai-v0.1.0.zip](https://github.com/cdy1206/copy-web-to-ai/raw/main/release/copy-web-to-ai-v0.1.0.zip)

下载后先解压。Chrome/Edge 的开发者模式不能直接加载 `.zip`，只能加载文件夹。解压出来的 `copy-web-to-ai` 文件夹里应该能看到 `manifest.json`。

### 2. 加载到浏览器

打开浏览器扩展管理页：

- Chrome: `chrome://extensions`
- Edge: `edge://extensions`

然后：

1. 开启“开发者模式”。
2. 点击“加载已解压的扩展”。
3. 选择刚刚解压出来的 `copy-web-to-ai` 文件夹。

注意：浏览器加载的是“解压后的文件夹”，不是 `.zip` 文件本身，也不是 GitHub 下载下来的源码文件夹。

### 从源码安装

如果你想自己改代码或重新构建，再使用这条路径：

```bash
git clone https://github.com/cdy1206/copy-web-to-ai.git
cd copy-web-to-ai
npm install
npm run build
```

然后在扩展管理页选择项目里的 `dist` 文件夹。

### 3. 打开你想复制的网页

推荐先试这些页面：

- ChatGPT: `https://chatgpt.com`
- Gemini: `https://gemini.google.com`
- Claude: `https://claude.ai`
- DeepSeek: `https://chat.deepseek.com`

这些站点默认可用。其他网站可以在 Copy Web to AI 设置里开启“允许所有网站”。

### 4. 点击浏览器工具栏里的 Copy Web to AI

你会看到这些按钮：

| 按钮 | 什么时候用 |
| --- | --- |
| 复制选区 | 只想复制你选中的一小段内容。 |
| 复制当前回答 | 在 AI 聊天页复制一条助手回答。 |
| 复制可见会话 | 复制当前已经显示出来的对话。 |
| 复制整页 | 复制当前网页已经加载到 DOM 里的整页内容。 |
| 解锁复制 | 当前网页禁止选择、禁止右键、禁止复制时先点它。 |
| 框选 OCR | 图片公式、截图、canvas、扫描件等无法直接读 DOM 的内容。 |

复制成功后，内容会进入剪贴板，直接粘贴到 AI、笔记、Markdown 编辑器里即可。

## 我该选哪个功能

| 你的目标 | 推荐操作 |
| --- | --- |
| 复制 AI 的最后一条回答 | `复制当前回答` |
| 复制当前屏幕附近的整段对话 | `复制可见会话` |
| 复制一篇网页或教程给 AI 总结 | `复制整页` |
| 复制网页里某几段文字和公式 | 选中内容后点 `复制选区` |
| 网页不让选文字 | 先点 `解锁复制`，再复制选区或整页 |
| 公式悬浮出来了但普通复制不对 | 鼠标移到公式上，用悬浮按钮复制 LaTeX |
| 内容是一张图、扫描件、canvas | `框选 OCR` |

## 它会保留什么

Copy Web to AI 会尽量保留这些结构：

- 标题
- 段落
- 列表
- 链接
- 表格
- 代码块
- KaTeX / MathJax / MathML / Gemini `data-math` 公式
- 行内公式 `$...$`
- 块级公式 `$$...$$`

复制出来的内容默认是 Markdown，公式会尽量保留为 LaTeX delimiter。这样粘给 AI 时，模型更容易读懂上下文，而不是拿到一坨丢格式的纯文本。

## 复制整页，不等于滚动截图

`复制整页` 不是截图，也不是 OCR。它直接读取当前网页已经加载到 DOM 里的内容，所以速度快、格式干净、不会把整张长图丢给 OCR。

但这里有一个重要限制：如果网页是无限滚动、虚拟列表或懒加载，浏览器还没加载出来的部分不会凭空出现。你可以先滚动到需要的位置，让网页把内容加载出来，再点 `复制整页`。

只有这些情况才建议走 `框选 OCR`：

- 内容本来就是图片。
- 内容在 canvas 里。
- 网页视觉上看得到，但 DOM 里没有可读文本。
- 你只想截取页面局部，而不是复制整页。

## MinerU OCR 怎么用

OCR 默认不会自动运行，也不会自动上传网页内容。你需要手动触发。

使用步骤：

1. 打开 Copy Web to AI 设置页。
2. 填入 MinerU Token。
3. 回到网页，点击 `框选 OCR`。
4. 拖拽选择当前可见区域。
5. 等待 OCR 结果自动复制到剪贴板。

设置里可以调整：

- MinerU Token
- MinerU 用户标识，可留空，扩展会尝试从 JWT 中读取
- OCR 语言，默认 `ch`
- OCR 超时时间

请不要把真实 Token 写进源码、README、issue 或日志。如果 Token 曾经发到聊天里，建议轮换。

## 为什么做这个插件

普通复制经常坏在这些地方：

- 公式变成乱码。
- 代码缩进丢了。
- 表格散成几行。
- 链接只剩文字。
- AI 聊天页面复制到一堆按钮和噪声。
- 某些网页禁止选择、禁止右键。
- 图片公式只能靠眼睛重打。

Copy Web to AI 的思路是：先尊重网页本身的数据结构。能本地提取，就本地提取；只有真的没有文本源时，才让 OCR 上场。

## 隐私和边界

- 不做 analytics。
- 不加载远程脚本。
- 不自动上传网页内容。
- 不抓取平台后台历史会话。
- 不调用 ChatGPT/Gemini/Claude/DeepSeek 的登录 API。
- MinerU OCR 只有在你手动框选后才上传裁剪图片。
- 不绕过 DRM、付费墙或用户当前不可见的内容。

默认权限只覆盖常见 AI 聊天网站。其他网站访问需要你在设置中主动开启。

## 常见问题

### 为什么复制整页没有拿到全部内容？

多数情况是网页用了懒加载、无限滚动或虚拟列表。先滚动页面，让内容加载出来，再复制整页。

### 为什么有些图片里的公式复制不到？

DOM 复制只能读取网页里的文本和结构。图片、扫描件、canvas 里的内容需要用 `框选 OCR`。

### 为什么 OCR 会失败？

常见原因包括 MinerU Token 失效、网络失败、OCR 超时或上传服务拒绝请求。先确认 Token 可用，再重试较小区域。

### 可以在任意网站使用吗？

可以。默认只在几个 AI 聊天站点启用；要在任意网站使用，请到设置里开启“允许所有网站”。

### 会不会把我的网页内容自动发出去？

不会。DOM 复制、选区复制、公式复制都在本地完成。只有你点击 `框选 OCR` 并完成框选后，裁剪出来的图片才会上传到 MinerU。
